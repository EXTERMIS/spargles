    Settings

    Sets how far every slider moves per step. Sliders with a range of 10 or more (dB, Hz, %) use this exact value. Smaller-range sliders (0 to 1 mixes, speed) use one tenth of it so they stay usable. You can always type an exact value in the box next to any slider. Off by default: new uploads are added to the library and your current track stays loaded (the first upload always loads). If automatic saving is also off, uploads load immediately.
